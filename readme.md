# Título

A composição parte do conceito de transformação explorando a capacidade de um sistema visual modificar-se em resposta à interação do utilizador. A intenção é criar um ambiente gráfico dinâmico no qual os elementos geométricos não apresentam um comportamento fixo mas reagem constantemente a estímulos externos. 
O movimento do rato funciona como elemento de influência sobre a composição provocando alterações na forma, na dimensão e na cor dos elementos. Deste modo, o utilizador deixa de ser apenas um observador e passa a participar diretamente na construção da experiência visual.
